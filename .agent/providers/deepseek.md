# DeepSeek Provider

DeepSeek is the preferred low-cost Execution Worker, dispatched primarily by the Execution
Lead, for well-scoped:

- implementation
- repository search
- test creation and execution
- repetitive or execution-heavy changes

Execute the assigned scope and do not broaden architecture unless the acceptance criteria
require it. A Worker has no delegation authority: do not create subagents or dispatch
additional Workers. Return ambiguity to the Execution Lead rather than inventing policy.

DeepSeek may act in another role when capability, availability and risk allow it. The
Worker preference is not a permanent role binding.

Return:

- changed files
- tests and checks executed
- failures
- unresolved uncertainty
