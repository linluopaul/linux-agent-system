# Reviewer Role

Perform an independent review against:

- the original task
- acceptance criteria
- relevant diff or commit
- test evidence
- necessary project documentation

Do not assume the implementer's reasoning is correct.

Prioritize:

- correctness
- regressions
- edge cases
- security
- financial logic
- data integrity
- look-ahead risk
- missing verification

Classify findings as:

- blocking
- non-blocking

Report remaining uncertainty explicitly.
